# dannypeter.com

Danny Peter's one-page site: tech help for local businesses in the Poconos.

Plain static HTML, hosted on GitHub Pages at https://dannypeter.com.

## Files

- `index.html` – the whole page (styles inline)
- `danny.jpg` – portrait
- `og.jpg` – the 1200×630 preview image that shows when the link is shared
- `favicon.svg`, `apple-touch-icon.png` – browser tab and home-screen icons
- `CNAME` – tells GitHub Pages to serve the site at dannypeter.com

## Editing

Edit `index.html` and push to `main`. GitHub Pages republishes within a minute or two.
